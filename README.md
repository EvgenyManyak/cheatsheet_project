# Python · Excel, CSV, Parquet — учебная шпаргалка

Учебная шпаргалка и воспроизводимый Jupyter Notebook по работе с тремя
основными табличными форматами в Python: Excel (`.xlsx`), CSV и Parquet.
Материал рассчитан на аналитика данных, который уже уверенно работает с
`pandas`, но хочет систематизировать практические приёмы: чтение из разных
источников, первичный осмотр, безопасное преобразование, визуализация и
сохранение результатов.

Все примеры воспроизводимы: демонстрационный набор `sales_df` генерируется
прямо в коде через `pd.DataFrame({...})` — внешние файлы для запуска не нужны.

## Содержание шпаргалки

PDF-документ состоит из 8 тематических разделов и итогового чек-листа:

1. **Введение и подготовка среды** — используемые библиотеки и их назначение,
   команды установки для Jupyter, Colab, PowerShell и Linux, проверка версий,
   диагностика частых ошибок импорта.
2. **Подключение к данным** — чтение Excel, CSV и Parquet из локального
   каталога, Google Drive (в Colab), по прямой ссылке и из публичного
   GitHub-репозитория. Параметры для каждого формата: листы и диапазоны
   Excel, разделитель и кодировка CSV, движок и сжатие Parquet.
3. **Первичный осмотр и полезные команды** — размер, типы, описательная
   статистика, пропуски, уникальные значения, выбор строк и столбцов,
   сортировка, шаблон `quick_inspect`.
4. **Анализ и преобразование данных** — обработка пропусков и дубликатов,
   проверка и преобразование типов, работа с датами, очистка текста,
   фильтрация, поиск выбросов, объединение наборов, агрегаты `groupby`,
   сводные таблицы `pivot_table`, `transform`, `value_counts`.
5. **Целостность и безопасность данных** — дисциплина `df_raw` /
   `df_work` / `df_clean`, риски незаметного изменения, контрольные итоги
   до и после преобразования, резервные копии, защита от потери типов при
   экспорте.
6. **Визуализация** — пять ключевых графиков на `matplotlib` и `seaborn`:
   столбчатая диаграмма, гистограмма, boxplot, линейный график, тепловая
   карта корреляций. Подготовка данных, настройка стиля, сохранение в файл.
7. **Сохранение результатов** — экспорт в Excel, CSV и Parquet с важными
   параметрами (индекс, имя листа, кодировка, разделитель, сжатие).
   Сохранение в локальную папку и Google Drive, проверка перечитыванием.
8. **Работа в Jupyter, Colab, PowerShell и Linux** — рецепты для каждой
   среды: запуск Jupyter, монтирование Google Drive, создание и активация
   виртуального окружения, клонирование репозитория, открытие ноутбука
   прямо из GitHub в Colab.

В конце — итоговый чек-лист для PDF, ноутбука и репозитория.

## Целевая аудитория

- Аналитик данных с опытом работы в Python и `pandas`.
- Базовый синтаксис Python и устройство DataFrame не объясняются.

## Установка библиотек

### Linux / macOS

```bash
# Создание виртуального окружения
python3 -m venv venv
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### Windows (PowerShell)

```powershell
# Создание виртуального окружения
python -m venv venv
.\venv\Scripts\Activate.ps1

# Установка зависимостей
pip install -r requirements.txt
```

> Если PowerShell выдаёт ошибку при активации скрипта, разрешите запуск один раз:
> `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`.

## Сделать репозиторий публичным

1. На GitHub откройте страницу репозитория.
2. Перейдите в `Settings` → `General` → в самом низу `Danger Zone`.
3. Нажмите `Change visibility` → `Public`.
4. Подтвердите изменение.

После этого репозиторий будет доступен по ссылке
`https://github.com/USERNAME/REPOSITORY`, а файлы можно скачивать напрямую
через `Download ZIP` или открывать ноутбук в Colab.
